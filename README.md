# rb-setup consumer smoke

Run the packaged [rb-setup](https://github.com/RubyElders/rb-setup) action without checkout or language setup steps on Linux, macOS and Windows. The workflow checks the paired default and explicit latest version, executable outputs, PATH and repeated installation.

Pushes, manual dispatch and a daily schedule exercise the immutable `v0.4.1` action tag. Application and development tests live in rb-setup.
